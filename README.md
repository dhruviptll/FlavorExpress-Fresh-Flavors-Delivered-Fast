# Project Title
**FlavorExpress – Digital Food Delivery Platform**

## Purpose of Website
FlavorExpress is a modern, responsive food delivery platform designed to connect users with the best local restaurants. The purpose of this project is to provide a seamless digital food hub where users can easily browse diverse menus, place orders, make secure simulated payments, and track their food delivery in real-time. It serves as a practical implementation of front-end web development concepts.

## Technologies Used
* **HTML5:** Used for the semantic structure and foundational layout of all web pages.
* **CSS3:** Used for styling, responsive design (utilizing CSS Grid and Flexbox), custom animations, and creating a modern, visually appealing user interface.
* **JavaScript:** Used for adding interactivity, such as dynamic cart calculations, multi-step form validation, tab switching, interactive star ratings, and simulating real-time order tracking.

## Main Features of Website
* **User Authentication:** Switchable Login and Registration pages with client-side validation and password strength indicators.
* **Interactive Menu & Filters:** A dynamic restaurant menu section with category filtering (e.g., Indian, Fast Food, Italian) and search functionality.
* **Multi-Step Ordering System:** A guided 3-step checkout process (Personal Details ➔ Food Selection ➔ Confirmation) with an automatic bill calculator.
* **Secure Payment UI:** An interactive payment selection page supporting expandable forms for UPI, Credit/Debit Cards, and COD.
* **Real-Time Tracking Simulation:** A visual progress timeline and mock map interface to simulate the delivery partner's journey.
* **Dynamic Feedback System:** A comprehensive review form featuring interactive star ratings, category-specific reviews, and selectable feedback tags.
* **Fully Responsive Design:** Optimized layout that seamlessly adapts to desktops, tablets, and mobile devices.

## Website Flow / Working
1. **Home Page (`index.html`):** The user lands on the main page, which highlights the platform's features, top food categories, and customer testimonials.
2. **Authentication (`login.html`):** The user can sign in or create a new free account to get started.
3. **Browsing (`restaurant.html`):** The user explores the menu, filters dishes by cuisine, and adds desired items to their floating cart.
4. **Checkout (`order.html`):** The user fills out their delivery address, reviews the selected food items, and checks the final bill including taxes and platform fees.
5. **Payment (`payment.html`):** The user selects their preferred payment method (PhonePe, GPay, UPI, Card, or COD) and securely completes the simulated transaction.
6. **Tracking (`tracking.html`):** Post-order, the user tracks their meal's status via an interactive timeline, from "Kitchen Preparing" to "Out for Delivery".
7. **Feedback (`feedback.html`):** After receiving the meal, the user can rate their experience and leave a detailed review to help improve the service.

## Conclusion
Building FlavorExpress served as an excellent hands-on project to master front-end web development. It successfully demonstrates the integration of HTML structure, CSS styling, and JavaScript logic to create a functional, user-centric, and professional digital product from scratch.
